# ADR 0004: 토큰 만료 시간

## 상태
채택

## 배경
액세스 토큰과 리프레시 토큰의 만료 시간을 정해야 한다.
만료가 길면 탈취 시 피해가 커지고, 짧으면 재로그인이 잦아진다.

## 선택지
별도로 비교하지 않고, 일반적인 권장 범위를 참고해 정했다.

## 결정
액세스 토큰은 30분, 리프레시 토큰은 7일로 한다.

## 이유
- 액세스 토큰은 짧게 두어 탈취됐을 때 쓸 수 있는 시간을 줄인다.
- 리프레시 토큰은 길게 두어 재로그인 빈도를 줄인다.

## 영향
- 만료 시간은 설정 값으로 두어 코드 수정 없이 바꿀 수 있게 한다.
- 액세스 토큰은 DB에 저장하지 않으므로 만료 전에 무효화할 수 없다.
