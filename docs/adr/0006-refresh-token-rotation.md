# ADR 0006: 리프레시 토큰 교체(rotation)

## 상태
채택

## 배경
토큰 재발급 시 리프레시 토큰을 그대로 둘지, 새로 발급할지 정해야 한다.

## 선택지
- 교체함: 재발급 시 새 리프레시 토큰을 발급하고 기존 토큰을 무효화
- 교체 안 함: 재발급 시 기존 리프레시 토큰을 유지

## 결정
재발급할 때 새 리프레시 토큰을 발급한다. 기존 토큰 무효화와 새 토큰 저장을 한 트랜잭션으로 처리한다.

## 이유
- 한 번 쓴 리프레시 토큰은 다시 쓸 수 없으므로, 탈취된 토큰의 재사용을 막는다.
- 한 트랜잭션으로 묶어 둘 중 하나만 성공하는 상태를 막는다.

## 영향
- 재발급 응답에 액세스 토큰과 리프레시 토큰을 모두 담는다.
- 클라이언트는 재발급 후 새 리프레시 토큰으로 바꿔 저장해야 한다.

## 향후 개선
- 이미 무효화된 토큰이 다시 들어왔을 때 해당 사용자의 다른 리프레시 토큰까지 무효화하는 처리
