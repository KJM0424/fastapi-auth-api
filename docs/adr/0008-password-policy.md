# ADR 0008: 비밀번호 조건

## 상태
채택

## 배경
PRD에 따라 회원가입 시 비밀번호 조건을 서버에서 검증한다. 조건을 정해야 한다.

## 선택지
- 길이 조건만 적용
- 길이와 문자 조합 조건 적용

## 결정
8자 이상, UTF-8 기준 72바이트 이하이고 영문과 숫자를 모두 포함해야 한다.

## 이유
- 조건이 단순해서 검증 로직과 오류 메시지를 쓰기 쉽다.
- bcrypt 5.0부터 72바이트를 넘는 비밀번호는 해싱 단계에서 `ValueError`가 발생한다(ADR 0002). 가입 단계에서 막아 이 오류가 나지 않게 한다.

## 영향
- 조건에 맞지 않으면 회원가입을 거부하고 오류 코드를 반환한다.
