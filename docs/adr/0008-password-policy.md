# ADR 0008: 비밀번호 조건

## 상태
채택

## 배경
PRD에 따라 회원가입 시 비밀번호 조건을 서버에서 검증한다. 조건을 정해야 한다.

## 선택지
- 8자 이상, 영문과 숫자 포함
- 8자 이상, 영문·숫자·특수문자 포함
- 길이 조건만 적용

## 결정
8자 이상이고 영문과 숫자를 모두 포함해야 한다.

## 이유
- 조건이 단순해서 검증 로직과 오류 메시지를 쓰기 쉽다.

## 영향
- 조건에 맞지 않으면 회원가입을 거부하고 오류 코드를 반환한다.
- 최대 길이는 정하지 않았다. ADR 0002의 72바이트 제한과 함께 검토가 필요하다.
