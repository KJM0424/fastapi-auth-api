# ADR 0009: 오류 응답 형식

## 상태
채택

## 배경
PRD에 따라 오류 응답을 일관된 형식으로 반환한다. FastAPI의 기본 오류 응답은 `{"detail": ...}` 형식이고, 입력 검증 오류는 다른 구조로 나온다.

## 선택지
- FastAPI 기본 형식 그대로 사용
- 공통 형식: `{"code": "...", "message": "..."}`

## 결정
모든 오류를 `{"code": "...", "message": "..."}` 형식으로 반환한다.

## 이유
- 오류 종류를 code로 구분할 수 있어 API 스펙을 일관되게 쓸 수 있다.

## 영향
- 입력 검증 오류를 포함해 FastAPI 기본 오류도 이 형식으로 바꾸는 예외 핸들러가 필요하다.
- code 목록은 API 스펙에 정리한다.
